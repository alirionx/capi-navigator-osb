First release of the CAPI Navigator service broker: an Open Service Broker (API v2.17) that lets
Cloud Foundry users order Kubernetes clusters from the cluster blueprints of
[CAPI Navigator](https://github.com/alirionx/capi-navigator).

## What it does

- **Catalog:** one service offering (`kubernetes-cluster`) with one plan per blueprint of a
  CAPI Navigator connection; the plan parameters (workers, machine size, Kubernetes version) come
  from the blueprint.
- **Provision and deprovision:** `cf create-service` creates a cluster from the blueprint,
  `cf delete-service` deletes it with cleanup of load balancers and volumes; progress shows in
  `cf service`.
- **Bind:** `cf bind-service` or `cf create-service-key` hands out the cluster's admin kubeconfig
  with `server`, `cluster` and `namespace`.
- **Stateless:** no database; instances are found by labels on their clusters, any replica answers
  any request.
- **Operations:** container image (non-root, read-only root file system), Helm chart, Compose file,
  `/healthz` and `/readyz`, JSON logs without credentials, Swagger UI at `/docs`.

## Install

- Image: `ghcr.io/alirionx/capi-navigator-osb:0.1.0`
- Helm chart: `oci://ghcr.io/alirionx/charts/capi-navigator-osb --version 0.1.0`
- Setup, configuration and registration in Cloud Foundry:
  [docs/operations.md](https://github.com/alirionx/capi-navigator-osb/blob/v0.1.0/docs/operations.md)

## Requirements

- CAPI Navigator with cluster blueprints (FP-34): `main` at commit `05240f3` or later, or the
  coming release 0.16.0.
- A technical user in CAPI Navigator with `view`, `clusters.create`, `clusters.delete` and
  `clusters.kubeconfig`, and an API token.

## Limits

- One instance is one cluster; no updates of plan or parameters.
- A binding is the admin kubeconfig: every developer of the space can read it, unbinding revokes
  nothing, it stays valid until the instance is deleted.
- Tested against a fake of the CAPI Navigator API and manually through the OSB API against a real
  CAPI Navigator (create, bind, `kubectl`, delete on AWS). The acceptance with a real Cloud Foundry
  (OSB4-F-03) is still open and follows in the next release.
